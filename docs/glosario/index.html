Glosario PSP

Términos de Java usados en las clases, en orden alfabético.

array (int[], Thread[])

Qué es

Fila de cajas numeradas que guardan el mismo tipo de dato. Se empieza a contar en 0.

Para qué sirve

Guardar varios valores u objetos juntos, por ejemplo 5 hilos o 10 enteros. .length dice cuántos hay.

Ejemplo mínimo
int[] numeros = {1, 2, 3};
System.out.println(numeros[0]);       // 1
System.out.println(numeros.length);   // 3

ArrayList

Qué es

Lista que crece sola cuando se añaden elementos. Entre < > se indica qué guarda.

Para qué sirve

Guardar cosas cuando no sabemos cuántas serán, por ejemplo los clientes que van llegando. A diferencia de un array, no tiene tamaño fijo.

Ejemplo mínimo
ArrayList<Thread> clientes = new ArrayList<>();
clientes.add(hilo);

boolean

Qué es

Tipo de dato que solo puede valer true (verdadero) o false (falso).

Para qué sirve

Guardar un sí o un no, por ejemplo si hay un cuadro en el almacén. Se puede negar con ! (!hayCuadro) y combinar con && (y).

Ejemplo mínimo
boolean hayCuadro = false;
hayCuadro = true;

constructor

Qué es

Método especial que se ejecuta al hacer new. Se llama igual que la clase y no lleva void.

Para qué sirve

Dar a un objeto sus datos iniciales. Así un hilo recibe el array con el que va a trabajar, porque run() no tiene parámetros.

Ejemplo mínimo
public HiloSuma(int[] numeros) {
    this.numeros = numeros;
}

double

Qué es

Tipo de dato para números con decimales.

Para qué sirve

Guardar importes de dinero o medidas. Se escribe con punto: 0.75.

Ejemplo mínimo
double dinero = 0;
dinero = dinero + 1.75;

FileWriter / Files

Qué es

FileWriter es la clase de Java que escribe texto en un fichero. Files.readAllLines lee un fichero entero y devuelve una lista con una entrada por línea.

Para qué sirve

Guardar y leer datos en ficheros de texto. FileWriter(ruta, true) añade al final en vez de borrar. Siempre hay que cerrar el fichero con close() y manejar IOException.

Ejemplo mínimo
FileWriter fw = new FileWriter("datos.txt", true);
fw.write("hola\n");
fw.close();
int lineas = Files.readAllLines(Path.of("datos.txt")).size();

for

Qué es

Bucle que repite un bloque de código un número de veces.

Para qué sirve

Recorrer un array o repetir algo, por ejemplo crear 5 hilos. Tiene tres partes: inicio, condición y paso.

Ejemplo mínimo
for (int i = 0; i < 5; i++) {
    System.out.println(i);   // 0 1 2 3 4
}

for (Thread t : lista)

Qué es

Forma corta del for para recorrer todos los elementos de una lista o array, uno en cada vuelta.

Para qué sirve

No hace falta contar posiciones: t es el elemento actual. Se lee «para cada hilo t de la lista».

Ejemplo mínimo
for (Thread t : clientes) {
    t.join();
}

getName()

Qué es

Método de Thread que devuelve el nombre del hilo.

Para qué sirve

Saber qué hilo está ejecutando un código, por ejemplo para mostrarlo en pantalla.

Ejemplo mínimo
Thread h = new Thread(new Contador(), "Hilo 1");
System.out.println(h.getName());   // Hilo 1

if

Qué es

Instrucción que ejecuta unas líneas solo si una condición es cierta.

Para qué sirve

Decidir entre hacer algo o no hacerlo. Por ejemplo, quedarse con una nota solo si es mayor que la mayor vista hasta ahora.

Ejemplo mínimo
if (nota > maximo) {
    maximo = nota;
}

IOException

Qué es

Error que lanza Java cuando falla una operación con ficheros: no existe, no hay permiso, el disco está lleno...

Para qué sirve

Java obliga a tenerlo en cuenta con try/catch cada vez que se usa un fichero.

Ejemplo mínimo
try {
    FileWriter fw = new FileWriter("datos.txt");
    fw.close();
} catch (IOException e) {
    System.out.println("No se puede abrir el fichero");
}

join()

Qué es

Método de Thread que hace esperar al hilo que lo llama hasta que el otro hilo termine.

Para qué sirve

Esperar a que acaben varios hilos antes de seguir, por ejemplo para mostrar un mensaje final. Obliga a manejar InterruptedException (main puede declarar throws InterruptedException).

Ejemplo mínimo
hilo.start();
hilo.join();
System.out.println("El hilo ha terminado");

.length

Qué es

Propiedad de un array que dice cuántos elementos tiene.

Para qué sirve

Recorrer un array entero sin escribir su tamaño a mano. No lleva paréntesis.

Ejemplo mínimo
int[] numeros = new int[10];
System.out.println(numeros.length);   // 10

main

Qué es

Método donde empieza a ejecutarse un programa Java.

Para qué sirve

Es el punto de entrada. Java empieza siempre por aquí, en el hilo llamado main.

Ejemplo mínimo
public static void main(String[] args) {
    System.out.println("Empieza el programa");
}

new Thread(objeto, "nombre")

Qué es

Forma de crear un hilo: se le da un objeto Runnable y un nombre.

Para qué sirve

Crear un hilo a partir de una clase con run() y ponerle un nombre fácil de reconocer.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

notify()

Qué es

Método que despierta a un hilo que está esperando con wait() sobre el mismo objeto.

Para qué sirve

Avisar a otro hilo de que algo ha cambiado. Solo despierta a uno, y no se puede elegir cuál.

Ejemplo mínimo
hayCuadro = true;
notify();

notifyAll()

Qué es

Como notify(), pero despierta a todos los hilos que esperan con wait() sobre el mismo objeto.

Para qué sirve

Cuando hay más de dos hilos esperando, notify() puede despertar al equivocado. Con notifyAll() cada hilo se despierta, comprueba su condición y se vuelve a dormir si no puede seguir.

Ejemplo mínimo
hayCuadro = false;
notifyAll();

@Override

Qué es

Etiqueta que avisa de que un método reemplaza al de la clase o interfaz original.

Para qué sirve

Hace que el compilador avise si te equivocas al escribir el nombre del método (por ejemplo Run en vez de run).

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Hola");
}

Principal

Qué es

Nombre que usa el profesor para la clase que contiene el main.

Para qué sirve

Reunir el código que crea y lanza los hilos. No es una palabra de Java: es una costumbre de nombre.

Ejemplo mínimo
public class Principal {
    public static void main(String[] args) {
        new Thread(new Gato(), "Gato").start();
    }
}

private

Qué es

Palabra clave que hace que un atributo solo se pueda usar dentro de su clase.

Para qué sirve

Guardar datos propios de la clase, como el array que recibe un hilo.

Ejemplo mínimo
private int[] numeros;

Random

Qué es

Clase de Java que genera números al azar.

Para qué sirve

Variar los tiempos o los valores en cada ejecución. nextInt(3) da 0, 1 o 2.

Ejemplo mínimo
Random azar = new Random();
int segundos = 1 + azar.nextInt(3); // 1, 2 o 3

return

Qué es

Instrucción que termina el método y entrega un valor a quien lo llamó.

Para qué sirve

Devolver un resultado, por ejemplo true o false. Un método que devuelve algo lleva su tipo en lugar de void.

Ejemplo mínimo
public boolean vender() {
    return true;
}

run()

Qué es

Método que contiene lo que hace el hilo.

Para qué sirve

Escribir aquí el trabajo del hilo. Java lo llama solo cuando haces start().

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Miau!");
}

Runnable

Qué es

Interfaz (un contrato) para clases que quieren ejecutarse en un hilo. Obliga a escribir run().

Para qué sirve

Definir qué hace un hilo sin heredar de Thread. Sirve aunque la clase ya herede de otra.

Ejemplo mínimo
public class Gato implements Runnable {
    @Override
    public void run() {
        System.out.println("Miau!");
    }
}

Scanner

Qué es

Clase de Java que lee lo que el usuario escribe por teclado.

Para qué sirve

Hacer menús y preguntar datos. nextInt() lee un número entero. System.in es el teclado.

Ejemplo mínimo
Scanner teclado = new Scanner(System.in);
int opcion = teclado.nextInt();

start()

Qué es

Método de Thread que pone en marcha el hilo.

Para qué sirve

Crear el hilo de verdad y que Java llame a run(). Si llamas a run() directamente, no hay hilo nuevo.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

switch

Qué es

Instrucción que mira un valor y salta al case que coincide.

Para qué sirve

Elegir entre varias opciones sin escribir muchos if. Cada case termina con break.

Ejemplo mínimo
switch (operacion) {
    case "suma":
        System.out.println("sumo");
        break;
    case "resta":
        System.out.println("resto");
        break;
}

synchronized

Qué es

Palabra clave que se pone en un método para que solo un hilo a la vez pueda estar dentro de él.

Para qué sirve

Evitar que dos hilos toquen a la vez el mismo objeto. Es imprescindible para usar wait() y notify().

Ejemplo mínimo
public synchronized void depositar(int numero) {
    // solo un hilo a la vez entra aquí
}

System.out.println

Qué es

Instrucción que escribe un texto en la pantalla y salta de línea.

Para qué sirve

Mostrar mensajes y resultados en la consola de NetBeans.

Ejemplo mínimo
System.out.println("Hilo 1: " + 5);   // Hilo 1: 5

this

Qué es

Palabra clave que significa «este objeto».

Para qué sirve

Distinguir el atributo de la clase de un parámetro con el mismo nombre.

Ejemplo mínimo
this.numeros = numeros;   // atributo = parámetro

Thread

Qué es

Clase de Java que representa un hilo de ejecución.

Para qué sirve

Crear, arrancar y controlar hilos. Cada objeto Thread es un hilo.

Ejemplo mínimo
Thread h = new Thread(new Perro());
h.start();

Thread.currentThread()

Qué es

Método que devuelve el hilo que está ejecutando ese código en este momento.

Para qué sirve

Preguntar «¿qué hilo soy?». Se usa dentro de run(), junto con getName().

Ejemplo mínimo
Thread actual = Thread.currentThread();
System.out.println(actual.getName());

Thread.sleep()

Qué es

Método que duerme el hilo actual durante los milisegundos que se le indican (1000 = 1 segundo).

Para qué sirve

Simular que algo tarda: un lavado, una máquina que fabrica una pieza. Obliga a escribir try/catch con InterruptedException. Se usa fuera de synchronized para no bloquear a los demás hilos.

Ejemplo mínimo
try {
    Thread.sleep(2000);
} catch (InterruptedException e) {
}

throws

Qué es

Palabra que se pone en la cabecera de un método para avisar de que puede lanzar un error de cierto tipo y dejarlo pasar.

Para qué sirve

Evitar escribir un try/catch en cada llamada a join() o sleep(): el método declara el error y quien lo llame se ocupa.

Ejemplo mínimo
public static void main(String[] args) throws InterruptedException {
    hilo.join();
}

try / catch

Qué es

Estructura que prueba un código y, si Java lanza un error de un tipo concreto, ejecuta otro bloque en lugar de parar el programa.

Para qué sirve

Es obligatorio con wait(), que puede lanzar InterruptedException (aviso de que alguien interrumpió la espera). Si no hacemos nada con el aviso, el catch queda vacío.

Ejemplo mínimo
try {
    wait();
} catch (InterruptedException e) {
}

wait()

Qué es

Método que duerme al hilo que lo llama y suelta el objeto para que otro hilo pueda entrar.

Para qué sirve

Esperar a que otro hilo avise de que ya se puede continuar. Solo se usa dentro de un método synchronized y obliga a escribir try/catch.

Ejemplo mínimo
while (hayCuadro) {
    try {
        wait();
    } catch (InterruptedException e) {
    }
}

while

Qué es

Instrucción que repite un bloque de código mientras se cumpla una condición.

Para qué sirve

Repetir algo sin saber cuántas veces. Si la condición es falsa desde el principio, el bloque no se ejecuta ninguna vez. Con wait() se usa while y no if, para volver a comprobar la condición al despertar.

Ejemplo mínimo
while (hayCuadro) {
    wait();
}

Ningún término coincide.
