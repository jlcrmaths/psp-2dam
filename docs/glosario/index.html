Glosario

Glosario PSP

Términos de Java usados en las clases, en orden alfabético.

+=

Qué es

Operador que suma a una variable lo que hay a la derecha y guarda el resultado en la misma variable.

Para qué sirve

Acumular un total sin repetir el nombre de la variable. dineroGanado += PRECIO es lo mismo que dineroGanado = dineroGanado + PRECIO.

Ejemplo mínimo
dineroGanado += PRECIO;

array (int[], Thread[])

Qué es

Fila de cajas numeradas que guardan el mismo tipo de dato. Se empieza a contar en 0.

Para qué sirve

Guardar varios valores u objetos juntos, por ejemplo 5 hilos o 10 enteros. .length dice cuántos hay.

Ejemplo mínimo
int[] numeros = {1, 2, 3};
System.out.println(numeros[0]);       // 1
System.out.println(numeros.length);   // 3

ArrayList

Qué es

Lista que crece sola cuando se añaden elementos. Entre < > se indica qué guarda.

Para qué sirve

Guardar cosas cuando no sabemos cuántas serán, por ejemplo los clientes que van llegando. A diferencia de un array, no tiene tamaño fijo.

Ejemplo mínimo
ArrayList<Thread> clientes = new ArrayList<>();
clientes.add(hilo);

boolean

Qué es

Tipo de dato que solo puede valer true (verdadero) o false (falso).

Para qué sirve

Guardar un sí o un no, por ejemplo si el pintor ya ha terminado. Se puede negar con ! (!terminado) y combinar con && (y).

Ejemplo mínimo
boolean terminado = false;
terminado = true;

BufferedReader

Qué es

Clase que lee un fichero de texto de forma cómoda, línea a línea, usando un FileReader por dentro.

Para qué sirve

Recorrer un fichero con readLine(). Hay que cerrarlo con close() cuando se termina de usar.

Ejemplo mínimo
BufferedReader br = new BufferedReader(new FileReader(fichero));

BufferedWriter

Qué es

Clase que escribe en un fichero de texto de forma cómoda, usando un FileWriter por dentro. Guarda el texto en memoria y lo manda al disco al cerrarlo.

Para qué sirve

Escribir líneas en un fichero con write() y newLine(). Si no se vacía con flush() o no se cierra con close(), el texto puede no llegar al disco.

Ejemplo mínimo
BufferedWriter bw = new BufferedWriter(new FileWriter(fichero, true));

close()

Qué es

Método que cierra un fichero abierto con FileReader, FileWriter, BufferedReader o BufferedWriter.

Para qué sirve

Soltar el fichero cuando se termina de usar. En un BufferedWriter, close() también vacía el buffer, igual que flush().

Ejemplo mínimo
bw.write("hola");
bw.close();

condición de carrera

Qué es

Error que ocurre cuando varios hilos leen y cambian el mismo dato a la vez y el resultado depende de quién llega antes.

Para qué sirve

Es un concepto, no una instrucción. Explica por qué cuenta++ desde varios hilos puede perder sumas: cada hilo lee el valor, calcula y lo guarda, y otro hilo puede haber guardado entre medias. Se evita con synchronized.

Ejemplo mínimo
int temp = cuenta;
// otro hilo puede cambiar cuenta aquí
cuenta = temp + 1;

constructor

Qué es

Método especial que se ejecuta al hacer new. Se llama igual que la clase y no lleva void.

Para qué sirve

Dar a un objeto sus datos iniciales. Así un hilo recibe el array con el que va a trabajar, porque run() no tiene parámetros.

Ejemplo mínimo
public HiloSuma(int[] numeros) {
    this.numeros = numeros;
}

do while

Qué es

Instrucción que repite un bloque de código y comprueba la condición al final, no al principio. El bloque se ejecuta siempre al menos una vez.

Para qué sirve

Repetir algo hasta que ocurra una cosa, como un menú que se muestra hasta que el usuario elige salir.

Ejemplo mínimo
do {
    menu = sc.nextInt();
} while (menu != 3);

double

Qué es

Tipo de dato para números con decimales.

Para qué sirve

Guardar importes de dinero o medidas. Se escribe con punto: 0.75.

Ejemplo mínimo
double dinero = 0;
dinero = dinero + 1.75;

else if

Qué es

Una condición más que se prueba solo si la del if anterior no se cumplió. Se pueden encadenar varias, y un else final recoge todo lo demás.

Para qué sirve

Elegir entre varios caminos: solo se ejecuta uno. Aquí, según el estado del semáforo, el lector entra directamente, espera o se une a los que ya leen.

Ejemplo mínimo
if (estado == LIBRE) {
    estado = CON_LECTORES;
} else if (estado == CON_ESCRITOR) {
    wait();
} else {
    // ya hay lectores: entra sin esperar
}

File

Qué es

Clase que representa un fichero del disco por su nombre. No lo abre: solo dice cuál es.

Para qué sirve

Pasar un fichero de un lado a otro sin abrirlo. Después se le pasa a FileReader o a FileWriter para leerlo o escribirlo.

Ejemplo mínimo
File fichero = new File("Discoteca.txt");

FileReader

Qué es

Clase que abre un fichero de texto para leerlo. Lanza FileNotFoundException si el fichero no existe.

Para qué sirve

Se envuelve en un BufferedReader para poder leer línea a línea.

Ejemplo mínimo
BufferedReader br = new BufferedReader(new FileReader(fichero));

FileWriter / Files

Qué es

FileWriter es la clase de Java que escribe texto en un fichero. Files.readAllLines lee un fichero entero y devuelve una lista con una entrada por línea.

Para qué sirve

Guardar y leer datos en ficheros de texto. FileWriter(ruta, true) añade al final en vez de borrar. Siempre hay que cerrar el fichero con close() y manejar IOException.

Ejemplo mínimo
FileWriter fw = new FileWriter("datos.txt", true);
fw.write("hola\n");
fw.close();
int lineas = Files.readAllLines(Path.of("datos.txt")).size();

final

Qué es

Palabra clave que, en una variable, impide cambiar su valor después de asignarlo.

Para qué sirve

Dejar claro que un valor no cambia, como el número de hilos que se crean. Si se intenta cambiar, el programa no compila.

Ejemplo mínimo
final int numLectores = 5;

flush()

Qué es

Método de la clase BufferedWriter. Vacía el buffer: manda al fichero todo el texto que se había guardado en memoria.

Para qué sirve

Un BufferedWriter no escribe en el fichero cada vez que se llama a write(): guarda el texto en memoria y lo manda de golpe. Sin flush() (o sin close()), el texto puede no llegar nunca al fichero.

Ejemplo mínimo
bw.write("Escritor0");
bw.newLine();
bw.flush();

for

Qué es

Bucle que repite un bloque de código un número de veces.

Para qué sirve

Recorrer un array o repetir algo, por ejemplo crear 5 hilos. Tiene tres partes: inicio, condición y paso.

Ejemplo mínimo
for (int i = 0; i < 5; i++) {
    System.out.println(i);   // 0 1 2 3 4
}

for (Thread t : lista)

Qué es

Forma corta del for para recorrer todos los elementos de una lista o array, uno en cada vuelta.

Para qué sirve

No hace falta contar posiciones: t es el elemento actual. Se lee «para cada hilo t de la lista».

Ejemplo mínimo
for (Thread t : clientes) {
    t.join();
}

getName()

Qué es

Método de Thread que devuelve el nombre del hilo.

Para qué sirve

Saber qué hilo está ejecutando un código, por ejemplo para mostrarlo en pantalla.

Ejemplo mínimo
Thread h = new Thread(new Contador(), "Hilo 1");
System.out.println(h.getName());   // Hilo 1

getPriority()

Qué es

Método de Thread que devuelve la prioridad de un hilo, un número del 1 al 10.

Para qué sirve

Saber con qué prioridad se está ejecutando un hilo, por ejemplo para mostrarla en pantalla.

Ejemplo mínimo
System.out.println(Thread.currentThread().getPriority());

if

Qué es

Instrucción que ejecuta unas líneas solo si una condición es cierta.

Para qué sirve

Decidir entre hacer algo o no hacerlo. Por ejemplo, quedarse con una nota solo si es mayor que la mayor vista hasta ahora.

Ejemplo mínimo
if (nota > maximo) {
    maximo = nota;
}

import static

Qué es

Línea que va arriba del fichero, tras package, y permite usar un método estático de otra clase sin escribir el nombre de la clase delante.

Para qué sirve

Con import static java.lang.Thread.sleep; se escribe sleep(3000); en vez de Thread.sleep(3000);. NetBeans la escribe con la bombilla.

Ejemplo mínimo
import static java.lang.Thread.sleep;

sleep(3000);

IOException

Qué es

Error que lanza Java cuando falla una operación con ficheros: no existe, no hay permiso, el disco está lleno...

Para qué sirve

Java obliga a tenerlo en cuenta con try/catch cada vez que se usa un fichero.

Ejemplo mínimo
try {
    FileWriter fw = new FileWriter("datos.txt");
    fw.close();
} catch (IOException e) {
    System.out.println("No se puede abrir el fichero");
}

join()

Qué es

Método de Thread que hace esperar al hilo que lo llama hasta que el otro hilo termine.

Para qué sirve

Esperar a que acaben varios hilos antes de seguir, por ejemplo para mostrar un mensaje final. Obliga a manejar InterruptedException (main puede declarar throws InterruptedException).

Ejemplo mínimo
hilo.start();
hilo.join();
System.out.println("El hilo ha terminado");

lectores y escritores

Qué es

Problema clásico de hilos: unos hilos solo leen un dato compartido y otros lo cambian. El programa tiene que evitar que se estorben.

Para qué sirve

Es un concepto, no una instrucción. Se resuelve con un objeto compartido que cuenta cuántos lectores y cuántos escritores lo usan, y con wait() y notifyAll() para esperar y avisar. En la versión más simple solo entra un hilo cada vez. Una versión más fina deja entrar a varios lectores a la vez, pero a un escritor siempre solo.

Ejemplo mínimo
// Espera si hay alguien dentro, sea lector o escritor.
while (lectores > 0 || escritores > 0) {
    wait();
}
lectores++;

.length

Qué es

Propiedad de un array que dice cuántos elementos tiene.

Para qué sirve

Recorrer un array entero sin escribir su tamaño a mano. No lleva paréntesis.

Ejemplo mínimo
int[] numeros = new int[10];
System.out.println(numeros.length);   // 10

List

Qué es

Interfaz de Java que representa una lista de elementos. ArrayList es una clase concreta que la implementa y es la que se crea con new.

Para qué sirve

Declarar una lista sin atarse a un tipo concreto: List hilos = new ArrayList<>(); Se usan add() para añadir, get() para obtener por posición y un for-each para recorrerla.

Ejemplo mínimo
List<Thread> hilos = new ArrayList<>();
hilos.add(new Thread(new Cliente(lavanderia)));

main

Qué es

Método donde empieza a ejecutarse un programa Java.

Para qué sirve

Es el punto de entrada. Java empieza siempre por aquí, en el hilo llamado main.

Ejemplo mínimo
public static void main(String[] args) {
    System.out.println("Empieza el programa");
}

MIN_PRIORITY, NORM_PRIORITY y MAX_PRIORITY

Qué es

Tres constantes de la clase Thread con las prioridades de referencia: MIN_PRIORITY vale 1, NORM_PRIORITY vale 5 y MAX_PRIORITY vale 10.

Para qué sirve

Dar nombre a los números de las prioridades, para no escribir 1, 5 o 10 a mano. Un hilo nuevo hereda la prioridad del hilo que lo crea; main tiene NORM_PRIORITY.

Ejemplo mínimo
h1.setPriority(Thread.MIN_PRIORITY);

new Thread(objeto, "nombre")

Qué es

Forma de crear un hilo: se le da un objeto Runnable y un nombre.

Para qué sirve

Crear un hilo a partir de una clase con run() y ponerle un nombre fácil de reconocer.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

notify()

Qué es

Método que despierta a un hilo que está esperando con wait() sobre el mismo objeto.

Para qué sirve

Avisar a otro hilo de que algo ha cambiado. Solo despierta a uno, y no se puede elegir cuál.

Ejemplo mínimo
numCuadros++;
notify();

notifyAll()

Qué es

Como notify(), pero despierta a todos los hilos que esperan con wait() sobre el mismo objeto.

Para qué sirve

Cuando hay más de dos hilos esperando, notify() puede despertar al equivocado. Con notifyAll() cada hilo se despierta, comprueba su condición y se vuelve a dormir si no puede seguir.

Ejemplo mínimo
numCuadros--;
notifyAll();

@Override

Qué es

Etiqueta que avisa de que un método reemplaza al de la clase o interfaz original.

Para qué sirve

Hace que el compilador avise si te equivocas al escribir el nombre del método (por ejemplo Run en vez de run).

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Hola");
}

Principal

Qué es

Nombre que usa el profesor para la clase que contiene el main.

Para qué sirve

Reunir el código que crea y lanza los hilos. No es una palabra de Java: es una costumbre de nombre.

Ejemplo mínimo
public class Principal {
    public static void main(String[] args) {
        new Thread(new Gato(), "Gato").start();
    }
}

private

Qué es

Palabra clave que hace que un atributo solo se pueda usar dentro de su clase.

Para qué sirve

Guardar datos propios de la clase, como el array que recibe un hilo.

Ejemplo mínimo
private int[] numeros;

Random

Qué es

Clase de Java que genera números al azar.

Para qué sirve

Variar los tiempos o los valores en cada ejecución. nextInt(3) da 0, 1 o 2.

Ejemplo mínimo
Random azar = new Random();
int segundos = 1 + azar.nextInt(3); // 1, 2 o 3

random() de Math

Qué es

Método de la clase Math que devuelve un número decimal al azar, mayor o igual que 0 y menor que 1.

Para qué sirve

Conseguir tiempos o valores distintos en cada ejecución. Hay que multiplicar antes de pasar a int: (int) (Math.random() * 500) da de 0 a 499, pero (int) (Math.random()) * 500 da siempre 0.

Ejemplo mínimo
Thread.sleep((int) (Math.random() * 500));

readLine()

Qué es

Método de la clase BufferedReader. Lee una línea del fichero y la devuelve como texto. Cuando ya no quedan líneas, devuelve null.

Para qué sirve

Contar o procesar las líneas de un fichero con un while que se repite hasta que devuelve null.

Ejemplo mínimo
int lineas = 0;
while (br.readLine() != null) {
    lineas++;
}

return

Qué es

Instrucción que termina el método y entrega un valor a quien lo llamó.

Para qué sirve

Devolver un resultado, por ejemplo true o false. Un método que devuelve algo lleva su tipo en lugar de void.

Ejemplo mínimo
public boolean vender() {
    return true;
}

run()

Qué es

Método que contiene lo que hace el hilo.

Para qué sirve

Escribir aquí el trabajo del hilo. Java lo llama solo cuando haces start().

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Miau!");
}

Runnable

Qué es

Interfaz (un contrato) para clases que quieren ejecutarse en un hilo. Obliga a escribir run().

Para qué sirve

Definir qué hace un hilo sin heredar de Thread. Sirve aunque la clase ya herede de otra.

Ejemplo mínimo
public class Gato implements Runnable {
    @Override
    public void run() {
        System.out.println("Miau!");
    }
}

Scanner

Qué es

Clase de Java que lee lo que el usuario escribe por teclado.

Para qué sirve

Hacer menús y preguntar datos. nextInt() lee un número entero. System.in es el teclado.

Ejemplo mínimo
Scanner teclado = new Scanner(System.in);
int opcion = teclado.nextInt();

semáforo

Qué es

Concepto, no una instrucción de Java: un objeto compartido que guarda en qué estado están unos datos y decide quién puede entrar en cada momento.

Para qué sirve

Coordinar hilos con papeles distintos. En lectores y escritores, el semáforo guarda un estado (libre, con lectores o con escritor) y un contador de lectores; hace esperar con wait() a quien no puede entrar y avisa con notify() cuando el estado vuelve a estar libre.

Ejemplo mínimo
if (estado == LIBRE) {
    estado = CON_LECTORES;
}
tLectores++;

setPriority()

Qué es

Método de Thread que cambia la prioridad de un hilo. La prioridad es un número del 1 al 10.

Para qué sirve

Pedir al planificador que dé más (o menos) tiempo de ejecución a un hilo. Se llama antes de start(). Es una sugerencia: el sistema operativo decide y el orden no queda garantizado.

Ejemplo mínimo
Thread h1 = new Thread(new Tarea(), "Hilo 1");
h1.setPriority(Thread.MAX_PRIORITY);
h1.start();

start()

Qué es

Método de Thread que pone en marcha el hilo.

Para qué sirve

Crear el hilo de verdad y que Java llame a run(). Si llamas a run() directamente, no hay hilo nuevo.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

static final

Qué es

Dos palabras clave juntas que crean una constante de la clase: static hace que pertenezca a la clase y no a cada objeto, y final hace que su valor no se pueda cambiar.

Para qué sirve

Dar nombre a valores fijos para no escribir números sueltos. Por convención se escriben en mayúsculas: LIBRE se lee mejor que 0.

Ejemplo mínimo
public static final int LIBRE = 0;
public static final int CON_ESCRITOR = 2;

switch

Qué es

Instrucción que mira un valor y salta al case que coincide.

Para qué sirve

Elegir entre varias opciones sin escribir muchos if. Cada case termina con break.

Ejemplo mínimo
switch (operacion) {
    case "suma":
        System.out.println("sumo");
        break;
    case "resta":
        System.out.println("resto");
        break;
}

synchronized

Qué es

Palabra clave que se pone en un método para que solo un hilo a la vez pueda estar dentro de él.

Para qué sirve

Evitar que dos hilos toquen a la vez el mismo objeto. Es imprescindible para usar wait() y notify().

Ejemplo mínimo
public synchronized void depositar(int numero) {
    // solo un hilo a la vez entra aquí
}

System.out.println

Qué es

Instrucción que escribe un texto en la pantalla y salta de línea.

Para qué sirve

Mostrar mensajes y resultados en la consola de NetBeans.

Ejemplo mínimo
System.out.println("Hilo 1: " + 5);   // Hilo 1: 5

this

Qué es

Palabra clave que significa «este objeto».

Para qué sirve

Distinguir el atributo de la clase de un parámetro con el mismo nombre.

Ejemplo mínimo
this.numeros = numeros;   // atributo = parámetro

Thread

Qué es

Clase de Java que representa un hilo de ejecución.

Para qué sirve

Crear, arrancar y controlar hilos. Cada objeto Thread es un hilo.

Ejemplo mínimo
Thread h = new Thread(new Perro());
h.start();

Thread.currentThread()

Qué es

Método que devuelve el hilo que está ejecutando ese código en este momento.

Para qué sirve

Preguntar «¿qué hilo soy?». Se usa dentro de run(), junto con getName().

Ejemplo mínimo
Thread actual = Thread.currentThread();
System.out.println(actual.getName());

Thread.sleep()

Qué es

Método que duerme el hilo actual durante los milisegundos que se le indican (1000 = 1 segundo).

Para qué sirve

Simular que algo tarda: un lavado, una máquina que fabrica una pieza. Obliga a escribir try/catch con InterruptedException. Se usa fuera de synchronized para no bloquear a los demás hilos.

Ejemplo mínimo
try {
    Thread.sleep(2000);
} catch (InterruptedException e) {
}

Thread.yield()

Qué es

Método que sugiere al planificador de Java que el hilo actual deja pasar a otro hilo.

Para qué sirve

Dar a los demás hilos la oportunidad de ejecutarse. Es solo una sugerencia: Java puede ignorarla y el hilo seguir. No lo uses para controlar el orden.

Ejemplo mínimo
for (int i = 0; i < 20000; i++) {
    Thread.yield();
}

throws

Qué es

Palabra que se pone en la cabecera de un método para avisar de que puede lanzar un error de cierto tipo y dejarlo pasar.

Para qué sirve

Evitar escribir un try/catch en cada llamada a join() o sleep(): el método declara el error y quien lo llame se ocupa.

Ejemplo mínimo
public static void main(String[] args) throws InterruptedException {
    hilo.join();
}

try / catch

Qué es

Estructura que prueba un código y, si Java lanza un error de un tipo concreto, ejecuta otro bloque en lugar de parar el programa.

Para qué sirve

Es obligatorio con wait(), que puede lanzar InterruptedException (aviso de que alguien interrumpió la espera). Si no hacemos nada con el aviso, el catch queda vacío.

Ejemplo mínimo
try {
    wait();
} catch (InterruptedException e) {
}

wait()

Qué es

Método que duerme al hilo que lo llama y suelta el objeto para que otro hilo pueda entrar.

Para qué sirve

Esperar a que otro hilo avise de que ya se puede continuar. Solo se usa dentro de un método synchronized y obliga a escribir try/catch.

Ejemplo mínimo
while (numCuadros == numMaxCuadros) {
    try {
        wait();
    } catch (InterruptedException e) {
    }
}

while

Qué es

Instrucción que repite un bloque de código mientras se cumpla una condición.

Para qué sirve

Repetir algo sin saber cuántas veces. Si la condición es falsa desde el principio, el bloque no se ejecuta ninguna vez. Con wait() se usa while y no if, para volver a comprobar la condición al despertar.

Ejemplo mínimo
while (numCuadros == numMaxCuadros) {
    wait();
}

write() y newLine()

Qué es

Métodos de la clase BufferedWriter. write() escribe un texto en el fichero y newLine() añade un salto de línea.

Para qué sirve

Escribir un texto por línea. Primero write() y después newLine() para que lo siguiente salga en otra línea.

Ejemplo mínimo
bw.write("Escritor0");
bw.newLine();
bw.flush();

Ningún término coincide.
