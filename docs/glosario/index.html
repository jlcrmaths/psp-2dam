Glosario PSP

Términos de Java usados en las clases, en orden alfabético.

array (int[], Thread[])

Qué es

Fila de cajas numeradas que guardan el mismo tipo de dato. Se empieza a contar en 0.

Para qué sirve

Guardar varios valores u objetos juntos, por ejemplo 5 hilos o 10 enteros. .length dice cuántos hay.

Ejemplo mínimo
int[] numeros = {1, 2, 3};
System.out.println(numeros[0]);       // 1
System.out.println(numeros.length);   // 3

constructor

Qué es

Método especial que se ejecuta al hacer new. Se llama igual que la clase y no lleva void.

Para qué sirve

Dar a un objeto sus datos iniciales. Así un hilo recibe el array con el que va a trabajar, porque run() no tiene parámetros.

Ejemplo mínimo
public HiloSuma(int[] numeros) {
    this.numeros = numeros;
}

for

Qué es

Bucle que repite un bloque de código un número de veces.

Para qué sirve

Recorrer un array o repetir algo, por ejemplo crear 5 hilos. Tiene tres partes: inicio, condición y paso.

Ejemplo mínimo
for (int i = 0; i < 5; i++) {
    System.out.println(i);   // 0 1 2 3 4
}

getName()

Qué es

Método de Thread que devuelve el nombre del hilo.

Para qué sirve

Saber qué hilo está ejecutando un código, por ejemplo para mostrarlo en pantalla.

Ejemplo mínimo
Thread h = new Thread(new Contador(), "Hilo 1");
System.out.println(h.getName());   // Hilo 1

.length

Qué es

Propiedad de un array que dice cuántos elementos tiene.

Para qué sirve

Recorrer un array entero sin escribir su tamaño a mano. No lleva paréntesis.

Ejemplo mínimo
int[] numeros = new int[10];
System.out.println(numeros.length);   // 10

main

Qué es

Método donde empieza a ejecutarse un programa Java.

Para qué sirve

Es el punto de entrada. Java empieza siempre por aquí, en el hilo llamado main.

Ejemplo mínimo
public static void main(String[] args) {
    System.out.println("Empieza el programa");
}

new Thread(objeto, "nombre")

Qué es

Forma de crear un hilo: se le da un objeto Runnable y un nombre.

Para qué sirve

Crear un hilo a partir de una clase con run() y ponerle un nombre fácil de reconocer.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

@Override

Qué es

Etiqueta que avisa de que un método reemplaza al de la clase o interfaz original.

Para qué sirve

Hace que el compilador avise si te equivocas al escribir el nombre del método (por ejemplo Run en vez de run).

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Hola");
}

Principal

Qué es

Nombre que usa el profesor para la clase que contiene el main.

Para qué sirve

Reunir el código que crea y lanza los hilos. No es una palabra de Java: es una costumbre de nombre.

Ejemplo mínimo
public class Principal {
    public static void main(String[] args) {
        new Thread(new Gato(), "Gato").start();
    }
}

private

Qué es

Palabra clave que hace que un atributo solo se pueda usar dentro de su clase.

Para qué sirve

Guardar datos propios de la clase, como el array que recibe un hilo.

Ejemplo mínimo
private int[] numeros;

run()

Qué es

Método que contiene lo que hace el hilo.

Para qué sirve

Escribir aquí el trabajo del hilo. Java lo llama solo cuando haces start().

Ejemplo mínimo
@Override
public void run() {
    System.out.println("Miau!");
}

Runnable

Qué es

Interfaz (un contrato) para clases que quieren ejecutarse en un hilo. Obliga a escribir run().

Para qué sirve

Definir qué hace un hilo sin heredar de Thread. Sirve aunque la clase ya herede de otra.

Ejemplo mínimo
public class Gato implements Runnable {
    @Override
    public void run() {
        System.out.println("Miau!");
    }
}

start()

Qué es

Método de Thread que pone en marcha el hilo.

Para qué sirve

Crear el hilo de verdad y que Java llame a run(). Si llamas a run() directamente, no hay hilo nuevo.

Ejemplo mínimo
Thread h1 = new Thread(new Contador(), "Hilo 1");
h1.start();

switch

Qué es

Instrucción que mira un valor y salta al case que coincide.

Para qué sirve

Elegir entre varias opciones sin escribir muchos if. Cada case termina con break.

Ejemplo mínimo
switch (operacion) {
    case "suma":
        System.out.println("sumo");
        break;
    case "resta":
        System.out.println("resto");
        break;
}

System.out.println

Qué es

Instrucción que escribe un texto en la pantalla y salta de línea.

Para qué sirve

Mostrar mensajes y resultados en la consola de NetBeans.

Ejemplo mínimo
System.out.println("Hilo 1: " + 5);   // Hilo 1: 5

this

Qué es

Palabra clave que significa «este objeto».

Para qué sirve

Distinguir el atributo de la clase de un parámetro con el mismo nombre.

Ejemplo mínimo
this.numeros = numeros;   // atributo = parámetro

Thread

Qué es

Clase de Java que representa un hilo de ejecución.

Para qué sirve

Crear, arrancar y controlar hilos. Cada objeto Thread es un hilo.

Ejemplo mínimo
Thread h = new Thread(new Perro());
h.start();

Thread.currentThread()

Qué es

Método que devuelve el hilo que está ejecutando ese código en este momento.

Para qué sirve

Preguntar «¿qué hilo soy?». Se usa dentro de run(), junto con getName().

Ejemplo mínimo
Thread actual = Thread.currentThread();
System.out.println(actual.getName());

Ningún término coincide.
