---
nombre: Dirección IP
---

## Qué es

Número que identifica a un ordenador en la red, por ejemplo 192.168.1.200. Para el propio ordenador se usa el nombre localhost.

## Para qué sirve

Indicar a qué ordenador queremos enviar los datos. Es como el edificio de una dirección; el puerto es el piso.

## Ejemplo mínimo

```java
// Direcciones que usaremos para conectar:
// "localhost"      -> este mismo ordenador
// "192.168.1.200"  -> otro ordenador de la red
```
