## Qué es

Clase de Java que lee lo que el usuario escribe por teclado.

## Para qué sirve

Hacer menús y preguntar datos. nextInt() lee un número entero. System.in es el teclado.

## Ejemplo mínimo

```java
Scanner teclado = new Scanner(System.in);
int opcion = teclado.nextInt();
```
