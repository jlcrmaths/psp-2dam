## Qué es

Modelo de comunicación en el que un programa, el cliente, pide cosas y otro programa, el servidor, las atiende y responde.

## Para qué sirve

Centralizar un recurso (datos, páginas, ficheros) en un servidor al que acceden muchos clientes por la red. El cliente habla con el usuario y el servidor hace el trabajo.

## Ejemplo mínimo

```java
// No es código: es el esquema de la conversación.
// Cliente  -> Servidor: "¿Qué hora es?"
// Servidor -> Cliente:  "16:30"
```
