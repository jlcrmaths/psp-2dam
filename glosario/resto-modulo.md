---
nombre: % (resto)
---

## Qué es

Operador que da el resto de una división entera. 7 % 2 vale 1 y 8 % 2 vale 0.

## Para qué sirve

Saber si un número es par (n % 2 == 0) o hacer que un contador vuelva a 0 al llegar a un límite (i % 7).

## Ejemplo mínimo

```java
if (n % 2 == 0) {
    System.out.println("par");
}
```
