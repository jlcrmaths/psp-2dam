## Qué es

Tipo de dato que solo puede valer true (verdadero) o false (falso).

## Para qué sirve

Guardar un sí o un no, por ejemplo si el pintor ya ha terminado. Se puede negar con ! (!terminado) y combinar con && (y).

## Ejemplo mínimo

```java
boolean terminado = false;
terminado = true;
```
