nombre: StringBuilder

## Qué es

Clase de Java que guarda un texto que se puede modificar. Un String normal no se puede cambiar.

## Para qué sirve

Dar la vuelta a un texto con reverse(). Después, toString() lo convierte otra vez en un String.

## Ejemplo mínimo

```java
String al = new StringBuilder("Hola").reverse().toString();  // aloH
```
