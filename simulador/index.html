Qué va pasando

    Piezas

    Cómo se usa

    1) Pulsa «＋ insertar línea» donde quieras una instrucción. 2) Pulsa la pieza (o arrástrala al hueco). También puedes pulsar una pieza (queda marcada) y luego pulsar el «＋» o el hueco donde quieras colocarla; con ⠿ pasa igual para mover una línea. 3) Rellena a mano lo que falte. Arrastra con ⠿ para mover una línea; ✕ la borra. Se omiten los try/catch de wait() y sleep().

    Código

    Pulsa «＋», escribe la instrucción tal como en Java (con su ;) y pulsa Enter. Bloques: while (condición) { · if (condición) { · if (condición) { } else { } · for (int i = 1; i <= 10; i++) {. Se omiten los try/catch.
