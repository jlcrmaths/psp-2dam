Crear hilos en Java

PSP · 2º DAM · Apartado 6.1

Objetivo

  • Crear un hilo en Java
  • Escribir su método run()
  • Ponerlo en marcha con start()
  • Ver que varios hilos se ejecutan a la vez

Teoría breve

  • Un hilo = un objeto de la clase Thread
  • Lo que hace el hilo se escribe en run()
  • start() arranca el hilo y llama a run()
  • Siempre hay un hilo main

Dos formas: extender Thread o implementar Runnable

Ejemplo: un hilo con Runnable


public class Saludo implements Runnable {
    @Override
    public void run() {
        System.out.println("¡Saludo desde un hilo!");
    }
}

// En main:
Thread hilo1 = new Thread(new Saludo(), "Hilo 1");
hilo1.start();

Error típico

hilo1.run() no crea un hilo nuevo.

Siempre usa start().

Ejercicio 1 · proyecto CrearHilos

Tres hilos. Cada uno cuenta del 1 al 10.

Salida: Hilo x: y

  • Contador implements Runnable
  • Principal crea los hilos con nombre

Ejecútalo varias veces. ¿Sale siempre igual?

Ejercicio 2 · proyecto EjemploPerrosGatos

  • Gato.run() muestra Miau!
  • Perro.run() muestra Guau!
  • Principal lanza los dos hilos

Solución 1: Contador


package crearhilos;

public class Contador implements Runnable {

    @Override
    public void run() {
        for (int i = 1; i <= 10; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
        }
    }
}

Solución 1: Principal


public class Principal {

    public static void main(String[] args) {
        Thread h1 = new Thread(new Contador(), "Hilo 1");
        Thread h2 = new Thread(new Contador(), "Hilo 2");
        Thread h3 = new Thread(new Contador(), "Hilo 3");

        h1.start();
        h2.start();
        h3.start();
    }
}

Solución 2: Gato y Perro


public class Gato implements Runnable {
    @Override
    public void run() { System.out.println("Miau!"); }
}

public class Perro implements Runnable {
    @Override
    public void run() { System.out.println("Guau!"); }
}

// Principal.main:
new Thread(new Gato(), "Gato").start();
new Thread(new Perro(), "Perro").start();

El orden de salida no está garantizado.
