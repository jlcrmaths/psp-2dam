Crear hilos en Java

PSP · 2º DAM · Apartado 6.1

Objetivo de la clase

  • Entender qué es un hilo
  • Crear un hilo con Runnable
  • Ponerlo en marcha con start()
  • Ver que varios hilos trabajan a la vez

¿Qué es un hilo?

Un programa normal hace una cosa cada vez, en orden.

Un hilo es un camino de ejecución. Con varios hilos, el programa puede hacer varias cosas a la vez.

Una idea para recordarlo

Una cocina con tres cocineros. Cada cocinero es un hilo. Los tres trabajan a la vez en la misma cocina.

Nadie decide quién termina antes. Por eso el orden no siempre es el mismo.

El hilo principal

Cuando un programa Java arranca, ya hay un hilo funcionando. Se llama main.

Es el último en terminar: el programa acaba cuando termina main.

Las piezas que vamos a usar

  • Thread: la clase de Java que representa un hilo
  • Runnable: un contrato para clases que se ejecutan en un hilo
  • run(): lo que hace el hilo
  • start(): pone el hilo en marcha

Dos formas de crear un hilo

  1. Heredar de Thread
  2. Implementar Runnable (la que usamos hoy)

Con Runnable funciona siempre, aunque la clase ya herede de otra. Java no permite heredar de dos clases.

Crear un hilo con Runnable: 4 pasos

  1. Escribe una clase que implemente Runnable
  2. Escribe su método run() con lo que debe hacer el hilo
  3. Crea un Thread y pásale un objeto de esa clase
  4. Llama a start()

Primer ejemplo: la clase Saludo


public class Saludo implements Runnable {
    @Override
    public void run() {
        System.out.println("¡Hola desde un hilo!");
    }
}

Pulsa la flecha para ir línea por línea.

Línea por línea

  • public class Saludo implements Runnable
    Creamos la clase Saludo y decimos que es Runnable: promete tener un método run().
  • @Override
    Avisa a Java de que run() cumple la promesa. Si lo escribes mal, Java te avisa.
  • public void run()
    Aquí va lo que hace el hilo.
  • System.out.println(...)
    Escribe un texto en pantalla.

Ponerlo en marcha


Thread hilo1 = new Thread(new Saludo(), "Hilo 1");
hilo1.start();
  • new Saludo(): crea el objeto con el trabajo
  • new Thread(..., "Hilo 1"): crea el hilo y le pone nombre
  • hilo1.start(): Java crea el hilo y llama a run()

Qué verás en pantalla

¡Hola desde un hilo!

Error típico

hilo1.run() no crea un hilo nuevo. Ejecuta el código en el hilo main, como una llamada normal.

Para crear el hilo, siempre start().

Ejercicio 1: tres contadores

Tres hilos. Cada uno cuenta del 1 al 10.

Salida de cada línea: Hilo x: y

Hilo 1: 1
Hilo 2: 1
Hilo 1: 2
…

Proyecto CrearHilos

Cómo pensarlo

  • ¿Cuántas clases necesito con run()? Una: Contador. Los tres hilos usan la misma.
  • ¿Cómo sabe cada hilo su número? Por el nombre del hilo.
  • ¿Cómo pregunto mi nombre? Thread.currentThread().getName()

Solución: Contador


public class Contador implements Runnable {

    @Override
    public void run() {
        for (int i = 1; i <= 10; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
        }
    }
}

Línea por línea

  • implements Runnable: esta clase puede ejecutarse en un hilo
  • for (int i = 1; i <= 10; i++): i empieza en 1, sube de uno en uno y para en 10
  • Thread.currentThread(): «el hilo que está ejecutando esto ahora mismo»
  • .getName(): «dime su nombre»
  • + ": " + i: pega los dos puntos y el número. Sale Hilo 2: 7

Crear los tres hilos


Thread h1 = new Thread(new Contador(), "Hilo 1");
Thread h2 = new Thread(new Contador(), "Hilo 2");
Thread h3 = new Thread(new Contador(), "Hilo 3");

h1.start();
h2.start();
h3.start();
  • Primero se crean los tres hilos, cada uno con su nombre
  • Después se arrancan los tres

¿Qué sale en pantalla?

Hilo 1: 1
Hilo 1: 2
Hilo 2: 1
Hilo 3: 1
Hilo 2: 2
…

Se mezclan. Ejecútalo varias veces: no sale igual. Es normal. El sistema decide quién avanza.

Ejercicio 2: Gato y Perro

  • Gato: su run() muestra Miau!
  • Perro: su run() muestra Guau!
  • Lanza un hilo de cada uno

Proyecto EjemploPerrosGatos

Solución: Gato y Perro


public class Gato implements Runnable {
    @Override
    public void run() {
        System.out.println("Miau!");
    }
}

public class Perro implements Runnable {
    @Override
    public void run() {
        System.out.println("Guau!");
    }
}

Lanzarlos


Thread hGato = new Thread(new Gato(), "Gato");
Thread hPerro = new Thread(new Perro(), "Perro");

hGato.start();
hPerro.start();
Miau!
Guau!

¿Sale siempre Miau! primero? Pruébalo varias veces.

Resumen

  • Un hilo es un objeto Thread
  • Lo que hace va en run()
  • start() lo pone en marcha. run() solo, no
  • El orden de la salida no está garantizado
  • El nombre del hilo: Thread.currentThread().getName()
